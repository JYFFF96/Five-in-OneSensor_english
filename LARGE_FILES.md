# Large debug libraries

Two third-party QXlsx debug libraries exceed the connected upload transport limit, so they are stored as lossless ZIP archives:

- `mmWaveRadar/libs/debug/QXlsx.lib.zip`
- `UltrasonicRadar/libs/debug/QXlsx.lib.zip`

Before building a Debug configuration, extract each archive in place. Each archive contains the original `QXlsx.lib` file. Release libraries and all source, UI, configuration, image, and documentation files are stored normally.
